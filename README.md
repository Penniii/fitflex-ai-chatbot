Aplikasi FitFlex AI dikembangkan sebagai platform asisten kesehatan pribadi berbasis web
untuk membantu pengguna merancang program olahraga, mengatur nutrisi, dan memantau
kebiasaan harian secara terstruktur. Sistem ini dibangun menggunakan framework Streamlit
dengan Python sebagai bahasa pemrogramannya. Untuk pemrosesan kecerdasan buatan,
aplikasi ini terintegrasi langsung dengan Google Gemini API yang bertindak sebagai mesin
pemroses percakapan dan evaluasi. Data fisik seperti berat badan dan tinggi badan diolah
menggunakan pustaka Pandas untuk menghitung nilai Body Mass Index (BMI) secara
real-time. Nilai BMI beserta target utama pengguna ini kemudian disuntikkan ke dalam
sistem prompt agar AI mampu memberikan rekomendasi yang presisi dan relevan.
